# SO:BIN DESK — 개인 학생관리

딸기우유 핑크 테마의 멘토용 학생 관리 웹앱입니다. 기존 ESTlanding 페이지를 덮어쓰지 않고 **student-desk/** 별도 경로로 제공됩니다.

## 접속
https://thqlssla-gif.github.io/ESTlanding/student-desk/

## 기능
- 대시보드: 학생 수 / 상담 중 학생 / 진행 과정 / 기한이 지난 할 일 / 최근 상담
- 학생 관리: 이름, 연락처, 희망 분야, 문의 출처, 상태, 다음 연락일, 상담 메모와 날짜별 상담 기록
- 과정 및 시간표: 과정, 시작/종료일, 수업 요일과 시간, 수업 회차 진행도, 학생 연결
- 일정 달력: 과정 수업일 / 개강·종강 / 콜백 / 업무
- 업무: 할 일, 콜백, 날짜, 상태 체크
- 문자 템플릿: 개인화 변수 자동 치환, 복사, 휴대폰 문자 앱 호출 (자동 발송 아님)
- 학생 CSV 가져오기: UTF-8 CSV 첫 줄에 이름,전화번호,상태,희망분야,메모
- 보안: 비밀번호 기반 PBKDF2 SHA-256(25만 회), AES-GCM 암호화 후 브라우저 localStorage 저장
- 암호화 JSON 백업 및 다른 기기에서 복원

## 꼭 읽어 주세요
1. **학생 정보는 GitHub에 저장되지 않습니다.** GitHub에는 HTML/CSS/JS 코드만 올라갑니다.
2. **PC ↔ 휴대폰 자동 동기화는 아직 없습니다.** 다른 기기에서는 암호화 백업 파일을 가져와 원래 비밀번호로 잠금 해제해야 합니다.
3. 비밀번호를 분실하면 기존 데이터를 복호화할 수 없습니다.
4. 브라우저 데이터 삭제/시크릿 모드 사용 시 로컬 기록이 사라질 수 있으니 백업 파일을 안전한 곳에 보관하세요.
5. 공개 GitHub Pages 사이트는 누구나 열 수 있습니다. 학생 정보가 노출되는 것을 방지하기 위해 실제 데이터는 사용자가 별도로 설정한 비밀번호로 암호화하며, 암호/백업 파일을 타인과 공유하지 마세요.
6. 외부 서버에서 학생 데이터가 동기화되거나 예약 알림이 발송되지는 않습니다. 필요한 경우 별도 보안 서버와 인증 체계가 필요합니다.
7. 이 버전은 참고 사이트의 학생/과정/시간표/일정/진도/문자 흐름을 재구성한 독립 웹앱이며, 원 사이트의 팀 계정/Excel .xlsx 자동 파싱/PWA 등 일부 기능은 포함되어 있지 않습니다.

## 백업
설정 · 백업 → 암호화 백업 내려받기 → 파일을 안전한 곳에 보관.
다른 기기에서 사이트를 열고 암호화 백업 가져오기 → 기존 비밀번호로 잠금 해제.

## KAIA DESK 원본 공개 예시 (2026-10-21)

공개 저장소 LigLess/kaia-desk의 index.html에 있는 makeDemo(), DEFAULT_SNIPPETS, TPL_DEFAULT를 확인해 공개 가상 예시만 reference-demo.js로 옮겼습니다.

- 학생 5명: 예시 이서준, 예시 박지민, 예시 최유나, 예시 정하늘, 예시 한도윤
- 교육 과정 7개: 정보처리기사 실기 평일반, SQLD 단기 주말반, 파이썬 기초, 리눅스마스터 2급, DBMS 과정 3개
- 할 일 3건: 한도윤 콜백, 교재 수량 확인, 국비 서류 스캔 정리
- 저장 문구 3개와 개강/종강 문자 안내 템플릿 5종. 원본의 개인 멘토 정보와 연락처는 제외했습니다.
- 원본과 동일한 수업 회차, 공휴일 제외 날짜, 격주 DBMS 일정, 파이썬과 리눅스 진도, 복수 과정 수강을 반영했습니다.

이전에 추가한 임의 예시(할 일 9건/문구 4개)는 조건에 맞으면 앱 잠금 해제 시 정확한 원본 예시로 교체됩니다. 설정 화면에서 예시만 제거하거나 다시 불러올 수 있습니다. 직접 입력한 실제 학생 기록은 유지됩니다.

공개 원본 사이트에 로그인해야 볼 수 있는 개별 계정, 팀 데이터, 실제 학생 기록에는 접근하지 않았습니다. 그런 데이터는 권한 있는 사용자의 내보내기 파일이 제공되어야 이전할 수 있습니다.

## 시간표_양식.xlsx 적용 (2026-10-21)

2026-10-21 업로드된 "시간표_양식.xlsx"의 "개강표" A1:J3을 읽어 2개 과정을 등록하도록 함:
- 정보처리기사 실기 평일반: 2026-11-02 ~ 2026-11-27, 월~금, 19:30~22:00, 시수(회차) 20, 홍길동, 301호
- SQLD 단기 주말반: 2026-11-07 ~ 2026-11-29, 토/일, 09:30~13:30, 시수(회차) 8, 강사 미정, 302호

student-desk/timetable-seed.js 는 이 2개 양식 행을 포함합니다. 로그인 해제 후 첫 실행 시 등록하며, 중복 생성 방지 설정을 함께 저장합니다. 기존 학생 상담 기록은 변경하지 않습니다.

이후 과정 > 엑셀 시간표 올리기 메뉴에서 동일한 헤더(구분,과정명,개강일,종강일,요일,시간,시수,강사,강의실,비고)의 XLSX 또는 CSV를 선택하면 브라우저에서 내용을 읽어 암호화된 현재 로컬 데이터에 저장합니다. 개인 엑셀의 원본 파일은 GitHub에 업로드하지 않습니다.

레이아웃은 요청한 공개 KAIA DESK 참고 화면과 같은 상단 가로 메뉴, 3단 홈 대시보드, 원형 진행 상태, 확인할 알림, 오늘 수업 카드로 업데이트했습니다. 원본 사이트의 디자인 자산을 재사용하지 않고 독립적으로 구현했습니다.


## SHOP DESK 예시 기반 워크플로 개선 (2026-10-29)

업로드된 `SHOP_DESK_예시.html`의 고객 후속관리·통합검색·업무 관리 패턴 중 학생 상담업무에 유용한 요소만 적용했습니다. **고객 주문/결제/상품, 팀 역할 전환 기능은 학생 정보와 무관해 가져오지 않았습니다.**

- **학생 콜백**: 연락 지연/오늘/향후 7일/그 이후/미지정 조건 분류, 학생별 상담 기록 바로 보기, 연락 결과와 다음 연락일 동시 저장.
- **홈 연락 체크**: 지연 및 오늘 연락할 학생 최대 3명을 상단 대시보드 아래에서 확인.
- **통합 검색**: 이름·전화번호·상담 메모·과정·업무를 브라우저 내부에서 검색. 상단 검색 아이콘, `Ctrl+K` / `⌘+K` / `/` 단축키 지원.
- **업무 확장**: 높음·보통·낮음 우선순위, 학생 연결, 진행 중/오늘·지연/완료/전체 필터.
- **CSV 내보내기**: 학생 명단을 엑셀에서 열 수 있는 CSV로 내보내기. 개인정보가 담긴 **평문 파일**이므로 확인 창을 보여줌. 민감 데이터 이동은 기존 암호화 백업을 권장.
- 기존 브라우저 AES-GCM 암호화 로컬 DB, 로그인 비밀번호, 학생·상담·과정 기록과 호환. DB 초기화 또는 새 샘플 자동 삽입 없음.

구현: `desk-workflow.js` (추가 기능) / `desk-workflow.css` (컴팩트 화면). `index.html`에서 `app.js` 로드 뒤에 기능을 연결하며, 암호화 해제 이전에는 학생 데이터 화면이 나타나지 않습니다. 작업 동기화 및 자동 문자 발송은 제공하지 않습니다.
